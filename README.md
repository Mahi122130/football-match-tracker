# ⚽ Football Match Tracker

A real-time football match tracking application built with React + TypeScript frontend and Node.js + Express backend.

## 🚀 Features

- **Real-time updates** using Server-Sent Events (SSE)
- **Live match tracking** with goals, cards, and events
- **Responsive design** with inline styling
- **Type-safe** with TypeScript
- **RESTful API** for match management

## 🛠️ Tech Stack

### Frontend
- React 18 + TypeScript
- Vite build tool
- React Router for navigation
- Real-time SSE connections

### Backend
- Node.js + Express
- TypeScript
- CORS enabled
- Server-Sent Events (SSE)
